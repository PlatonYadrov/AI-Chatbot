## 🛠️ Ручное тестирование

### Тест через API

#### 1. Загрузка документа
```bash
curl -X POST "http://localhost:6000/ingest" \
  -F "file=@test_document.pdf"
```

#### 2. Поиск без реранкинга
```bash
curl -X POST "http://localhost:7000/query" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "Что такое машинное обучение?",
    "k": 3,
    "use_reranking": false
  }'
```

#### 3. Поиск с реранкингом
```bash
curl -X POST "http://localhost:7000/query" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "Что такое машинное обучение?",
    "k": 3,
    "use_reranking": true,
    "rerank_top_k": 3
  }'
```

### Тест через веб-интерфейс

#### 1. Ingestion API
- Откройте: http://localhost:6000/docs
- Используйте `/ingest` endpoint
- Загрузите тестовый документ

#### 2. Online-RAG API
- Откройте: http://localhost:7000/docs
- Используйте `/query` endpoint
- Протестируйте разные запросы

#### 3. Qdrant Dashboard
- Откройте: http://localhost:6333/dashboard
- Проверьте коллекцию `rag_chunks`
- Просмотрите точки данных

### ❌ Проблемы и решения

#### Проблема: "Online-RAG сервис недоступен"
```bash
# Решение:
docker-compose logs online-rag
docker-compose restart online-rag
```

#### Проблема: "Коллекция пуста"
```bash
# Решение: загрузите документы
python test_full_rag_system.py  # Запустит тест ingestion
```

#### Проблема: "Ошибка реранкинга"
```bash
# Решение: проверьте логи
docker-compose logs online-rag | grep reranking
```
