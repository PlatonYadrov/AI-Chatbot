# 🚀 Один запрос для проверки всей RAG системы

## 📋 Быстрая проверка одной командой

### 1. Проверка через curl
```bash
curl -X POST "http://localhost:7000/query" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "Что такое машинное обучение?",
    "k": 3,
    "use_reranking": true,
    "rerank_top_k": 3
  }' | jq '.'
```

### 2. Проверка через Python (один скрипт)
```bash
python test_one_request.py
```

### 3. Проверка через веб-интерфейс
1. Откройте: http://localhost:7000/docs
2. Найдите endpoint `/query`
3. Нажмите "Try it out"
4. Введите:
   ```json
   {
     "query": "Что такое машинное обучение?",
     "k": 3,
     "use_reranking": true,
     "rerank_top_k": 3
   }
   ```
5. Нажмите "Execute"

## 🔧 Диагностика проблем

### Проблема: "Connection refused"
```bash
# Решение: запустить сервисы
docker-compose up -d
```

### Проблема: "Empty sources"
```bash
# Решение: загрузить документы
curl -X POST "http://localhost:6000/ingest" -F "file=@test.pdf"
```

### Проблема: "No reranking"
```bash
# Решение: проверить LangChain
docker-compose logs online-rag | grep reranking
```

### Проблема: "Slow response"
```bash
# Решение: проверить ресурсы
docker stats
```

## 🚀 Автоматизация

### Скрипт для CI/CD
```bash
#!/bin/bash
# test_rag.sh

echo "Testing RAG system..."

# Запуск сервисов
docker-compose up -d
sleep 30

# Тест
response=$(curl -s -X POST "http://localhost:7000/query" \
  -H "Content-Type: application/json" \
  -d '{"query": "test", "k": 1, "use_reranking": true}')

if echo "$response" | jq -e '.sources | length > 0' > /dev/null; then
    echo "✅ RAG system works!"
    exit 0
else
    echo "❌ RAG system failed!"
    exit 1
fi
```
