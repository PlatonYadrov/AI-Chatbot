# Что делает `from __future__ import annotations`

`from __future__ import annotations` — это специальный импорт в Python, который включает «отложенную» (или ленивую) обработку аннотаций типов. Он доступен начиная с Python 3.7 и по умолчанию включён в Python 3.11+, но во многих проектах его явно подключают, чтобы код вёл себя одинаково на версиях 3.8–3.10.

## Зачем он нужен

В Python до 3.11 аннотации типов вычисляются сразу при загрузке модуля. Это означает, что если вы используете в аннотации класс, который объявлен ниже по файлу (или находится в блоке `if TYPE_CHECKING`), то интерпретатору он ещё неизвестен. Приходилось:

* оборачивать имена в кавычки (`"Chunk"`),
* или переносить объявления, чтобы избежать `NameError`/циклических импортов.

Импорт из `__future__` меняет поведение: аннотации не вычисляются сразу, а сохраняются как строки. Python откладывает их реальное разрешение до тех пор, пока они действительно не понадобятся (например, статическому анализатору, `typing.get_type_hints` и т.д.). Это:

* убирает необходимость ставить кавычки вокруг «будущих» типов,
* упрощает взаимные ссылки между классами и функциями,
* ускоряет импорт модулей, потому что типы не нужно вычислять мгновенно.

## Как это выглядит на практике

```python
from __future__ import annotations

class Node:
    def __init__(self, left: Node | None = None, right: Node | None = None) -> None:
        self.left = left
        self.right = right
```

Без импорта из `__future__` этот код в Python 3.10 пришлось бы писать так:

```python
class Node:
    def __init__(self, left: 'Node | None' = None, right: 'Node | None' = None) -> None:
        ...
```

## В связке с `typing.get_type_hints`

Когда вам всё же нужно получить реальные объекты типов (например, внутри валидаторов), используйте `typing.get_type_hints`. Он «распакует» строковые аннотации и вернёт настоящие классы. При этом он умеет работать с отложенными аннотациями, если передать текущий глобальный/локальный namespace:

```python
from __future__ import annotations
from dataclasses import dataclass
from typing import get_type_hints

@dataclass
class Tree:
    children: list[Tree]

hints = get_type_hints(Tree, globals(), locals())
assert hints['children'] == list[Tree]
```

## Когда он не нужен

В Python 3.11 и новее отложенные аннотации включены по умолчанию (PEP 563 отменён, но эффект перенесён в PEP 649). Если проект гарантированно работает только на 3.11+, импорт можно опустить. Однако в нашем коде мы поддерживаем 3.9–3.10, поэтому явное указание `from __future__ import annotations` делает поведение одинаковым везде.

## Итог

* Импорт активирует отложенное вычисление аннотаций типов.
* Помогает писать взаимосвязанные классы без кавычек и циклических импортов.
* Делает код чище и ускоряет импорт модулей.
* Для Python 3.11+ это поведение уже встроено, но ради совместимости мы подключаем его вручную.
